## Структура папок

```
<Дисциплина>/
├── README.md
├── <N> semester/
│   ├── README.md
│   └── labN/
│       ├── ЛРN.pdf      отчёт
│       ├── README.md    название работы
│       └── src/         исходный код, если сохранился
└── Coursework/         курсовая: пояснительная записка и код
```

Номер семестра считается внутри дисциплины: «1 semester» — первый семестр, в котором она читалась, «2 semester» — второй. Номера лабораторных совпадают с номерами в отчётах, поэтому в некоторых дисциплинах они идут с пропусками.
